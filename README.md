# Simulador Medina

Simulador simples de fluxo de pagamento imobiliário, feito em HTML, CSS e JavaScript puro.

## O que ele faz

- calcula preço final após desconto;
- soma ato, intermediárias, chaves e financiamento;
- calcula automaticamente o saldo em parcelas mensais;
- permite adicionar várias intermediárias;
- confere se a soma do fluxo fecha com o preço final;
- gera uma mensagem formatada para WhatsApp;
- funciona no celular e no computador.

## Como usar

Abra o arquivo `index.html` no navegador.

Não precisa instalar nada.
